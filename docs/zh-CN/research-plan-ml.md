# EleD 多模型应用方案

本方案把 EleD 特征归档交给多种下游模型，形成可复现的应用研究。外部研究
工作区负责数据适配器、模型代码、权重和数值结果；EleD 仓库负责描述符 API、
特征归档合约和描述符级验证。

## 研究问题

同一份保留 RDKit 原子/键编号的 EleD 归档，能否基于一次电子结构计算，
同时供传统表格模型、GCN、GAT、GIN 和 Chemprop 使用，并完成分子性质回归和
原子级反应性预测？

本研究评价接口能力和实际模型使用效果，并按照预先声明的数据和计算协议报告
不同描述符组与模型结构的表现。

已有许多研究把 tight-binding 电子结构特征加入机器学习。EleD 的贡献是完成软件
交接：稳定保留 RDKit 原子/键身份，明确单位和缺失原因，一份归档供多种模型复用，
并测量完整计算成本。因此证据必须同时覆盖小样本有效性和大样本运行扩展性。

## 第一阶段的两个案例和数据来源

| 案例 | 粒度 | 主要来源 | 目标 | 作用 |
| --- | --- | --- | --- | --- |
| 反应性 | 原子 | RegioSQM20 公开导出，加上核对权利后的 ESNUEL/ESNUEL-ML ERDA 归档 | EAS 反应原子集合；MCA、MAA | 第一个原子级案例，覆盖小样本和大样本 |
| 光谱性质 | 分子 | Joung 等，Scientific Data 2020；Figshare v3 `10.6084/m9.figshare.12045567.v3` | 吸收峰和发射峰 | 第一个分子级案例 |

GNN-SOM、SET-LSF 和其他反应条件数据集在两个案例建立稳定的归档和模型合约后
进入后续实验，作为扩展案例使用。

每个来源都建立 manifest，记录来源 URL、commit 或版本、许可证、文件 SHA256、
行数、结构解析状态、目标覆盖率、筛选规则和去重规则。冻结论文和数据记录中引用的
源记录作为数据依据，并将随模型软件分发的镜像作为单独标识的便利副本保存。

## 固定特征组

所有模型读取同一归档，训练期变换只在训练折内拟合。

* **A，结构特征：** RDKit 原子和键特征、局部拓扑以及可选 Morgan 指纹。
* **B/C，核心电子特征：** GFN1 或 GFN2 电荷、HOMO、LUMO、能隙、偶极矩、
  自旋、总电荷和 SCF 诊断。
* **D，布居特征：** Mulliken/Löwdin 壳层布居、s/p/d 布居、密度汇总和构象统计。
* **E，键和前线特征：** Wiberg、Mayer、HOMO/LUMO 前线重叠和 π 键级。
* **F，反应性特征：** 固定几何的 Fukui、局部软度、亲电性和电荷差分。
* **G，可靠性特征：** 构象均值、标准差、范围、有效计数和失败标记。

导出时保留 `null` 和明确的缺失原因。模型适配器可以根据拟合分区填补并加入
缺失指示器。零保留为有效物理值，缺失状态由独立的原因字段表示。

## 图表示

图适配器保留 RDKit 原子编号。节点包含结构和 EleD 原子特征，边包含 RDKit 键
特征以及 EleD 键描述符，分子量信息放入全局特征。溶剂和反应条件作为独立全局
输入，便于分别评价启用或省略环境信息的模型。

原子级任务对每个节点输出分类分数或回归值。光学任务使用 mean、sum 或 attention
pooling 得到分子向量，再与全局向量拼接。图适配器放在外部研究工程，EleD 运行时
专注于描述符生成和归档导出。

## 模型矩阵

### 传统模型

使用 Ridge 和 ElasticNet 作为线性参考，ExtraTrees 和 Random Forest 作为稳健非线性
基线，LightGBM/XGBoost 或 HistGradientBoosting 作为主要表格比较。原子标签使用
一行一个原子的矩阵，但评价仍按分子加权。分子级模型使用原子和键描述符的固定汇总：
均值、总和、最大值、最小值、标准差、芳香原子子集统计和反应性分位数。

### 图模型

第一版采用以下小型模型：

| 模型 | 初始设置 |
| --- | --- |
| GCN | 4 层，hidden 128，残差连接，dropout 0.1 |
| GAT | 3–4 层，hidden 128，4 或 8 个 heads，dropout 0.1 |
| GIN | 4 层，hidden 128，双层 MLP，可学习 epsilon |
| Chemprop | D-MPNN 深度 3，hidden 300，FFN 深度 2–3，dropout 0.1 |

GCN/GAT/GIN 使用 AdamW，学习率 `1e-3`；Chemprop 使用 `1e-4`–`5e-4`；weight
decay 为 `1e-5`，batch size 32–64，梯度裁剪 5，最多 200 epochs，连续 30 个验证
epoch 无改善即停止。声明的搜索范围为 hidden 64/128/256、层数 2–6、dropout
0/0.1/0.2/0.3 和学习率 `1e-4`/`3e-4`/`1e-3`。每个模型和任务搜索 20–50 个 trial，
使用预先声明的 5 个随机种子。

Chemprop 使用外部自定义 featurizer 加入 EleD 原子和键字段。其默认分子 head 可用于
光学性质；原子任务需要节点 embedding head 和保留分子边界的排序损失。

## 任务目标和损失

吸收和发射使用独立 head，或共享 backbone 加两个带 mask 的回归 head。报告 nm 和
eV 下的 MAE/RMSE、Spearman、校准覆盖率和运行时间。`e_abs_ev` 表示吸收峰对应的
光子能量；`xtb_gap_ev` 表示作为输入描述符使用的基态 xTB 轨道能隙。

EAS 和 SOM 保留多个正原子，使用 weighted BCE 或 focal loss（`gamma=2`），并可加入
listwise ranking loss。报告分子级 top-1/top-3/top-5 命中率、MRR、nDCG、PR-AUC 和
ROC-AUC。全局原子 accuracy 作为辅助指标，分子级指标承担主要比较。

MCA/MAA 等连续目标报告原子级和分子级 MAE、RMSE、(R^2)、Spearman，并按元素、芳香性
和官能团分层统计误差。

## 数据划分和泄漏控制

主划分为 Bemis–Murcko scaffold 的 80/10/10，并加入 Morgan radius 2、1024 bit、
Tanimoto 0.7 的 cluster 约束。一个分子的所有记录、构象和原子必须留在同一分区。
测试 manifest 在特征选择和调参前封存。

光学数据额外建立溶剂迁移划分：发色团可以出现在训练集，但测试溶剂条件未出现在训练
集。该任务必须显式提供溶剂/环境特征。同一发色团/溶剂的重复记录保留 DOI，并在划分
前按冻结规则处理。

## 模型选择和不确定性

超参数、填补、缩放和特征选择在训练分区内使用确定性的分组折选择。验证集作为开发检查
报告；最终模型用 train+valid 重拟合，测试集只评估一次。报告每个种子、均值、标准差和
分子 bootstrap 95% 区间。模型选择使用训练和验证数据，测试集校准结果作为描述性
指标报告。

## 小样本和大样本证据

所有估计都以分子或反应记录为独立单位；划分和不确定性分析始终把同一单位内的
原子预测放在一起。

小样本研究从同一份冻结数据中取 50、100、250 和 500 个分子；原子标签任务使用尽量
平衡的最大子集。采用重复 scaffold 划分，报告不同种子的均值和标准差、学习曲线，
以及达到固定误差或排序指标所需要的样本数。Ridge/ElasticNet、浅层树模型和小型 GIN
或 Chemprop 覆盖小样本研究。只有验证结果支持更大模型时才将其纳入主比较。

大样本研究使用完整光学归档，以及 ESNUEL 规模或其他许可明确的反应归档。需要测量
吞吐量、峰值内存、并行扩展、特征覆盖率、归档大小、缓存复用和模型训练时间。昂贵的
xTB 阶段执行一次，成本在所有表格和图模型之间摊销；通过归档复用和引擎调用次数
记录这条工作流的实际成本。

软件比较的主要对象是 RDKit-only 特征、可复现的直接 xTB 脚本或已发表描述符导出，
以及 EleD 归档。预测提升只是结果之一；得到有效模型所需的时间、映射失败、可复现性
和归档复用同样重要。

## EleD 插件要测量的结果

每次运行还记录描述符覆盖率、缺失原因、构象和 SCF 失败率、xTB engine calls、运行时间、
归档大小、缓存命中率以及 native/compiled 数值一致性。报告同一份归档供所有声明模型
使用时的调用次数和复用情况。

## 执行里程碑

1. 固定两个来源的 manifest、协议哈希和划分 ID。
2. 用 20–50 个分子或记录 dry run，验证原子和键映射。
3. 生成 RegioSQM20、ESNUEL 和光学归档，完成描述符级检查。
4. 运行 A/B/C/D 表格基线，归档候选折分数。
5. 使用同一图 schema 增加 GCN、GAT、GIN 和 Chemprop 适配器。
6. 完成小/大样本反应性研究和光谱回归研究。
7. 做特征组、GFN1/GFN2、构象和溶剂消融。
8. 发布指标、成本、覆盖率、失败记录、负结果和全部哈希。

模型代码、源数据、训练权重和结果表保存在被忽略的外部研究工作区。EleD 的改动只应
涉及描述符定义、归档合约和保证交接可复现的验证。
